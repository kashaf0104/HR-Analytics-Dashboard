# HR-Analytics-Dashboard


📊 HR Analytics Dashboard (Power BI)
This project presents an interactive HR Analytics Dashboard built using Power BI, aimed at analyzing employee data and identifying key factors influencing employee attrition.
🔧 Tools & Technologies Used
Power BI
Power Query (Data Cleaning & Transformation)
Microsoft Excel (Data Source)

📁 Dataset
The dataset contains employee-related information such as:
Age
Gender
Department
Job Role
Salary
Years at Company
Attrition status


⚙️ Data Preparation
Cleaned and transformed raw data using Power Query
Handled missing values and corrected data types
Created calculated columns and measures for better insights


📌 Key KPIs
Total Employees: 1470
Attrition Count: 237
Attrition Rate: 16.1%
Average Age: 37 years
Average Salary: 6.5K
Average Years at Company: 7 years


📊 Dashboard Insights
Attrition by Education: Highest attrition observed in Life Sciences and Medical fields
Attrition by Age Group: Most employees leaving are aged 26–35
Attrition by Salary Slab: Higher attrition in lower salary ranges (up to 5K)
Attrition by Job Role: Laboratory Technicians and Sales Executives show higher attrition
Attrition by Years at Company: Employees tend to leave more in early years
Gender-based Attrition: Comparison between male and female employees


🎯 Key Takeaways
Lower salary and early career stages are major contributors to attrition
Certain job roles and departments need focused retention strategies
Workforce planning can be improved using these insights


🚀 Project Objective
To help HR teams:
Understand employee behavior
Reduce attrition rate
Make data-driven HR decisions


📌 Features
Interactive filters and slicers
Dynamic visuals and KPIs
Easy-to-understand layout for decision-making
🔗 Conclusion
This dashboard provides a comprehensive overview of HR metrics and helps organizations take proactive steps to improve employee retention and overall workforce management.
